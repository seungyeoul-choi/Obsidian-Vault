# Redis

Redis는 캐시, 분산 락, 임시 상태 저장, 빠른 카운터에 자주 사용되는 인메모리 데이터 저장소다.

## 이 위키에서 다룰 주제

- 캐시 전략
- 캐시 무효화
- 분산 락
- TTL 설계
- 장애 시 fallback
