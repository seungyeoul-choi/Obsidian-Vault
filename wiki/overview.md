# Overview

이 위키는 주문 처리 시스템을 개발하는 백엔드 개발자의 실무 지식과 학습을 누적하기 위한 LLM Wiki다.

## 현재 중심축

- 주문 처리 시스템 최적화
- Java와 Spring Boot 기반 백엔드 개발
- MySQL, Redis, ElasticSearch를 활용한 데이터 처리
- Kafka 기반 비동기 메시징
- AWS, Docker, Kubernetes 기반 운영 환경
- 매일 1시간 기술 학습의 누적

## 운영 방식

원천 자료는 `raw/`에 보관하고, Codex는 이를 읽어 `wiki/`에 요약, 개념, 프로젝트 문서로 통합한다. 질문 답변 중 다시 볼 가치가 있는 내용은 `wiki/questions/` 또는 `wiki/syntheses/`에 남긴다.
